# H5 Overlay Sample

H5 clients can connect directly when they run in a local environment that permits WebSocket access to `127.0.0.1`.

Typical use cases:

- Local browser source overlays.
- Local control panels.
- Debug pages for developers.

## Browser example

```html
<button id="connect">Connect</button>
<pre id="log"></pre>

<script type="module">
  const log = document.querySelector('#log')
  const PORT_START = 49152
  const PORT_END = 65535
  const SCAN_BATCH_SIZE = 128
  const HELLO_TIMEOUT_MS = 500
  const giftEffects = {
    '5655': () => document.body.classList.add('rose-effect'),
    '6064': () => print('GG!'),
    '7569': () => document.body.classList.add('controller-boost')
  }

  function print(message) {
    log.textContent += `${message}\n`
  }

  async function connectCandidate(port) {
    const socket = new WebSocket(`ws://127.0.0.1:${port}/v1/third-party`)

    return new Promise((resolve) => {
      const timer = setTimeout(() => {
        socket.close()
        resolve(null)
      }, HELLO_TIMEOUT_MS)

      socket.addEventListener(
        'message',
        (event) => {
          clearTimeout(timer)
          try {
            const hello = JSON.parse(event.data)
            if (
              hello.type === 'SERVER_HELLO' &&
              hello.product === 'tiktok_live_studio' &&
              hello.channel === 'third-party-im' &&
              hello.version === '1.0.0'
            ) {
              resolve(socket)
              return
            }
          } catch {
            // Treat malformed first messages as an unrelated local service.
          }
          socket.close()
          resolve(null)
        },
        { once: true }
      )

      socket.addEventListener('error', () => {
        clearTimeout(timer)
        socket.close()
        resolve(null)
      })
    })
  }

  async function scanBatch(startPort) {
    const endPort = Math.min(startPort + SCAN_BATCH_SIZE - 1, PORT_END)
    const candidates = await Promise.all(
      Array.from({ length: endPort - startPort + 1 }, (_, index) => connectCandidate(startPort + index))
    )
    const winner = candidates.find((socket) => socket !== null) ?? null
    for (const socket of candidates) {
      if (socket && socket !== winner) socket.close()
    }
    return winner
  }

  async function connect() {
    for (let batchStart = PORT_START; batchStart <= PORT_END; batchStart += SCAN_BATCH_SIZE) {
      const socket = await scanBatch(batchStart)
      if (!socket) continue

      socket.send(JSON.stringify({
        type: 'AUTH',
        app_id: 'your_app_id',
        key_id: 'your_key_id',
        secret: 'your_secret',
        version: '1.0.0'
      }))

      socket.addEventListener('message', (event) => {
        const message = JSON.parse(event.data)
        print(JSON.stringify(message, null, 2))

        if (message.type === 'EVENT' && message.event === 'live.gift') {
          const payload = message.payload
          const effect = giftEffects[String(payload.gift?.id)]
          if (effect && payload.repeat_end) effect()
        }
      })

      print(`connected to ${new URL(socket.url).port}`)
      return
    }

    print('LIVE Studio endpoint not found')
  }

  document.querySelector('#connect').addEventListener('click', connect)
</script>
```

Select IDs in the [Gift Catalog](/reference/gift-catalog). The example waits for `repeat_end=true` so one combo does not replay the effect on each cumulative update. In production, remove the hard-coded rules from the page and load them from trusted local configuration.

The scanner keeps concurrency bounded because the dynamic range contains 16,384 ports. It never sends credentials until a candidate has returned the exact supported `SERVER_HELLO`.

## Security notes

- Avoid shipping production credentials inside public web assets.
- Prefer local packaged clients or controlled development tools for credentialed access.
- Do not expose the local WebSocket connection through a remote proxy.
